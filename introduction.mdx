Achylo Protocol is a decentralized peer-to-peer escrow system built on the **Base blockchain**, purpose-built for LATAM and emerging markets. It lets anyone trade USDC against local fiat currencies — from Cuban Pesos to Colombian Pesos to Venezuelan Bolívars — with every trade secured by smart contracts instead of a central intermediary. No bank, no middleman, no counterparty trust required: the protocol's escrow logic enforces the rules on-chain.

Whether you are an individual looking to move value across borders, a merchant who wants to accept crypto payments, or a developer integrating payment infrastructure into your product, Achylo Protocol provides the rails you need.

## Supported Network

Achylo Protocol is deployed on **Base**, an Ethereum Layer 2 network built by Coinbase and designed for fast, low-cost transactions.

| Environment | Network | Chain ID |
|---|---|---|
| Production | Base Mainnet | `8453` |
| Testing | Base Sepolia | `84532` |

<Note>
  All protocol activity — escrow contracts, CUBT token transfers, payment settlements — runs on Base. Even if you deposit funds from another chain (Ethereum, Arbitrum, Polygon, and more), they are automatically bridged and converted to USDC on Base before entering the protocol.
</Note>

### Base Currency: USDC

Every trade and payment on Achylo is denominated in **USDC** (USD Coin). Amounts throughout the protocol are expressed in **micro-USDC**, where:

```
1 USDC = 1,000,000 micro-USDC
```

This means a value of `5000000` in the API or smart contract represents exactly **5.00 USDC**. Keep this in mind when building integrations or reading on-chain data.

### Gas-Free Experience

Achylo Protocol **sponsors gas fees** for all on-chain interactions. You do not need ETH or any native token to pay for transactions — just USDC in your wallet and you are ready to trade.

## User Tiers

Achylo Protocol uses a tiered user system that unlocks additional features and privileges as you participate more actively in the ecosystem.

| Tier | Description |
|---|---|
| **New** | Default tier for all newly connected wallets |
| **Active** | Granted after completing a minimum number of trades |
| **Merchant** | For businesses and high-volume traders accepting payments |
| **Gold** | Top-tier users with access to premium features and reduced fees |
