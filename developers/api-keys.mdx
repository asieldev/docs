API keys allow your servers to interact with the Achylo API without requiring a wallet signature on every request. They are the recommended authentication method for all programmatic integrations — including creating payment links, querying payment status, and any other server-to-server calls.

## Key format

Every Achylo API key follows this structure:

```
achylo_<64 hex characters>
```

**Example:**
```
achylo_a3f2c8b9d4e1f6a7c2b8d9e3f1a4c7b2a3f2c8b9d4e1f6a7c2b8d9e3f1a4c7b2
```

## Limits

- You can have a **maximum of 10 active keys** per account at any time.
- Keys **do not expire automatically** — revoke them manually when they are no longer needed.

## Creating a key

<Steps>

### Go to achylo.com and connect your wallet

Navigate to [achylo.com](https://achylo.com) and connect the wallet associated with your account.

### Open User Profile

Click your **User Profile** icon in the top-right corner of the dashboard.

### Scroll to Developer API Keys

Find the **Developer API Keys** section on your profile page.

### Enter an optional label

Give your key a descriptive label so you can identify it later — for example, `"Production"`, `"Staging"`, or `"Local Dev"`.

### Click New Key

Click the **New Key** button to generate your key.

<Warning>
  Your API key is displayed **only once**, immediately after creation. Copy it now and store it in a secure location such as an environment variable or secrets manager. You cannot retrieve the key value again after leaving this screen.
</Warning>

</Steps>

## Using your API key

Pass the key in the `X-API-Key` header on every request to the Achylo API.

```http
POST /api/payment-links
X-API-Key: achylo_a3f2c8b9...
Content-Type: application/json
```

The following examples show how to authenticate and create a payment link in TypeScript, Python, and PHP. Store your key in the `ACHYLO_API_KEY` environment variable — never hardcode it in source files.

<CodeGroup>

```typescript TypeScript / Node.js
const ACHYLO_API_KEY = process.env.ACHYLO_API_KEY!;

const response = await fetch('https://api.achylo.com/api/payment-links', {
  method: 'POST',
  headers: {
    'X-API-Key': ACHYLO_API_KEY,
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    amount: '10000000',                               // 10 USDC (micro-USDC)
    receiver: '0x992b874a816E6A6D4Ebcb1Eb6977962F061df51f',
    description: 'Order #1234',                       // optional
    expiresInMinutes: 1440,                           // optional — 24 hours
    webhookUrl: 'https://yoursite.com/webhooks/achylo', // optional
    webhookSecret: process.env.ACHYLO_WEBHOOK_SECRET,  // optional
  }),
});
```

```python Python
import os, requests

ACHYLO_API_KEY = os.environ['ACHYLO_API_KEY']

response = requests.post(
    'https://api.achylo.com/api/payment-links',
    headers={
        'X-API-Key': ACHYLO_API_KEY,
        'Content-Type': 'application/json',
    },
    json={
        'amount': '10000000',                                     # 10 USDC
        'receiver': '0x992b874a816E6A6D4Ebcb1Eb6977962F061df51f',
        'description': 'Order #1234',                             # optional
        'expiresInMinutes': 1440,                                 # optional — 24 hours
        'webhookUrl': 'https://yoursite.com/webhooks/achylo',     # optional
        'webhookSecret': os.environ.get('ACHYLO_WEBHOOK_SECRET'), # optional
    },
)
```

```php PHP
$apiKey = getenv('ACHYLO_API_KEY');

$ch = curl_init('https://api.achylo.com/api/payment-links');
curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_POST           => true,
    CURLOPT_HTTPHEADER     => [
        'X-API-Key: ' . $apiKey,
        'Content-Type: application/json',
    ],
    CURLOPT_POSTFIELDS => json_encode([
        'amount'           => '10000000',    // 10 USDC
        'receiver'         => '0x992b874a816E6A6D4Ebcb1Eb6977962F061df51f',
        'description'      => 'Order #1234',   // optional
        'expiresInMinutes' => 1440,             // optional — 24 hours
        'webhookUrl'       => 'https://yoursite.com/webhooks/achylo', // optional
        'webhookSecret'    => getenv('ACHYLO_WEBHOOK_SECRET'),        // optional
    ]),
]);
$response = json_decode(curl_exec($ch), true);
curl_close($ch);
```

</CodeGroup>

## Security best practices

Your API key grants full programmatic access to your Achylo account. Treat it with the same care as a password.

<Warning>
  Never commit API keys to source code, Git repositories, or any version-controlled files. If a key is accidentally exposed, revoke it immediately from the dashboard and generate a new one.
</Warning>

- **Use environment variables** — store your key in `ACHYLO_API_KEY` and read it at runtime. For production systems, prefer a dedicated secrets manager such as AWS Secrets Manager or HashiCorp Vault.
- **Separate keys per environment** — create distinct keys for `Development`, `Staging`, and `Production` so you can revoke one without affecting others.
- **Rotate keys periodically** — replace keys on a regular schedule and immediately if you suspect a key has been compromised.
- **Revoke unused keys** — delete any key that is no longer actively used. You can have at most 10 active keys, so keeping them tidy also ensures you never run out of capacity.
